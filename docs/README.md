## Visão Geral

Este repositório documenta o processo de desenvolvimento de uma aplicação de gestão de tarefas tipo Kanban, com foco numa solução simples e iterativa.

O fluxo de trabalho do projeto segue as fases:

- requisitos;
- design;
- planeamento de desenvolvimento;
- planeamento de testes;
- implementação.

## Fases

- Requisitos: definição do problema, objetivos e critérios de aceitação.
- Design: estrutura da interface, fluxos e organização da aplicação.
- Planeamento: tarefas, prioridades e roadmap.
- Testes: validação funcional e critérios de qualidade.
- Implementação: construção da aplicação Angular com funcionalidade de quadro Kanban.
